Hola equipo,

He publicado en la rama `main` una actualización importante con nuevas funcionalidades para la app móvil.

## 🎯 ¿Qué hay de nuevo?

Se han agregado 4 nuevos endpoints REST que permiten:

✅ **Pausar partidas** - El host puede pausar en cualquier momento
✅ **Reanudar partidas** - Continuar donde se dejó (hasta 24h después)
✅ **Abandonar partidas** - Cualquier jugador puede irse sin afectar otros
✅ **Terminar partidas** - El host puede finalizar para todos

Además, todas las partidas se guardan automáticamente en el servidor durante 24 horas, perfecta para apps móviles donde los usuarios pueden cerrar la app y reconectar después.

## 🔌 Endpoints nuevos (resumen)

| Endpoint | Permisos | Acción |
|----------|----------|--------|
| `POST /pause` | Solo host | Pausa la partida (recoverable) |
| `POST /resume` | Solo host | Reanuda desde pausa |
| `POST /leave` | Cualquiera | Abandona sin borrar partida |
| `POST /end` | Solo host | Termina para todos |

**Todos usan el mismo formato:**
```json
{
  "playerName": "Juan"
}
```

## 📱 Flujo típico en app móvil

### Pausar y reconectar después
```
1. Usuario hace tap en "Pausar" (en app web funciona, mobile lo hará igual)
2. → Llamar: POST /api/games/{code}/pause
3. → Escuchar: socket.on('gamePaused', ...)
4. → Mostrar: "Partida pausada - Tap para reanudar"
5. Usuario cierra app (desconexión)
6. Usuario abre app 6 horas después
7. → Llamar: GET /api/games/{code}
8. → Mostrar: Estado pausada con opción "Reanudar"
9. Usuario hace tap en "Reanudar"
10. → Llamar: POST /api/games/{code}/resume
11. → ¡Partida continúa donde estaba!
```

## 🎯 Puntos importantes

1. **Solo el host** puede pausar, reanudar y terminar
   - Cualquier jugador puede abandonar

2. **Persistencia automática**
   - Se guarda al pausar, reanudar, abandonar, terminar
   - Expira después de 24 horas
   - Si servidor reinicia, se recuperan las partidas

3. **Eventos en tiempo real**
   - Todos reciben notificaciones via Socket.IO
   - No necesitas pooling o fetch periódico

4. **Manejo de desconexiones**
   - Si pierden conexión, partida sigue en servidor
   - Al reconectar, pueden ver estado actual
   - Perfecto para apps móviles

## ❓ Preguntas frecuentes

**P: ¿Cuánto tiempo dura una sesión pausada?**
R: 24 horas. Después se descarta automáticamente.

**P: ¿Puedo abandonar en medio de una pregunta?**
R: Sí, en cualquier momento.

**P: ¿Si pierdo conexión, ¿qué pasa?**
R: La partida sigue en el servidor. Al reconectar, verás el estado actual.

**P: ¿El host puede ver quién abandonó?**
R: Sí, recibe un evento `playerLeft` con el nombre.

**P: ¿Necesito cambiar algo en la web?**
R: No, ya está implementado. Los botones ya están en la interfaz.
